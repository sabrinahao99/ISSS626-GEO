# Hands-on Exercise 3 Data

This folder contains the local reproducible data used by Chapter 6.

- `modis_2023_Indonesia.csv` was downloaded from NASA FIRMS public country yearly summary files.
- `forestfires.csv` is the Bangka-Belitung subset prepared from the Indonesia MODIS 2023 table.
- `Kepulauan_Bangka_Belitung.*` was created from the geoBoundaries Indonesia ADM1 boundary for Bangka-Belitung Islands.

The original course page used prepared files with the same study area name, but the raw files were not exposed in the rendered course site repository.
