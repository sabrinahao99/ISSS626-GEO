# Hands-on Exercise 4 Data

The folder contains the Hunan county boundary and the Hunan 2012 development indicator table supplied in `data4.zip`.

- `geospatial/Hunan.shp` and companion files contain 88 county-level polygons.
- `aspatial/Hunan_2012.csv` contains the county indicators, including `GDPPC`.
- The source boundary is WGS 84. The page creates an EPSG:32650 projected copy for distance calculations.
