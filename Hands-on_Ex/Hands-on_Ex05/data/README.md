# Hands-on Exercise 5 Data

This folder contains the Hunan county boundary layer and the Hunan 2012 indicator table used for Chapter 9.

- `geospatial/Hunan.shp` and its companion files contain 88 county-level polygons.
- `aspatial/Hunan_2012.csv` contains the development indicators, including `GDPPC`.
- `aspatial/Dictionary.xlsx` contains the supplied field descriptions.
